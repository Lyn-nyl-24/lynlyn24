LaTeX (web)

KaTeX turns each LaTeX label into MathML. The browser lays out the symbols as text. The paths, arrowheads, curves and dashes come from TikZ; TeX supplies each label’s position. Labels can be selected and exposed to assistive technology. Browser font metrics can differ slightly from XeLaTeX.

SVG

XeLaTeX and dvisvgm produce a portable vector image with the labels stored as outlines. Use this version when you want the TeX glyph placement preserved or need a separate image file. The image uses alternative text in the note; its outlines are not selectable text.

Quiver exports TikZ-cd LaTeX and is used during authoring. Both views are hosted here and switch without JavaScript.
