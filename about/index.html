About and privacy

Lynlyn24 is an independent notebook. Cite a note using its stable tag.

Korean translation

Korean translations of the original blog posts are generated on the author’s computer. Use EN to compare the original wording of a definition or proof. Formulas, diagrams and reference tags are shared by both editions.

Browser data

Search runs in the current page. The site uses no analytics and serves fonts from the same origin. The browser stores your theme preference and preferred reading language for blog posts.

Comments

Loading comments connects your browser to Giscus and shares the public note address. Comments and GitHub usernames are public on GitHub Discussions. If you sign in, your browser keeps a Giscus session for the current tab.

Hosting

GitHub Pages logs visitor IP addresses for security purposes. GitHub Pages data collection
