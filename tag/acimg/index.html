The image and inverse image functors

Toni Annala, Diagram Chasing in Abelian Categories, Section 2.3.

Definition 2.3.1#

Let f:X→Yf : X \to Y be a map. We define the image functor associated to ff from the category of subobjects of XX to the category of subobjects of YY by sending each subobject UU to the image of U→X→YU \to X \to Y . If we have a map of subobjects U→U′U \to U^{\prime }, then fU′f U^{\prime } is a subobject trough which U→X→YU \to X \to Y factors, so we have a map fU→fU′f U \to f U^{\prime }. Functorality is satisfied by the uniqueness of maps of subobjects.

Using the image functor, we obtain yet another characterization for monicness of a map.

Proposition 2.3.2#

A map f:X→Yf : X \to Y is monomorphism if and only if the image functor associated to ff is injective.

Proof#

If ff is not monic, then it has a nonzero kernel K→XK \to X. As K→X→Y=0K \to X \to Y = 0, we have that fK=0=f0f K = 0 = f 0, i.e., the image functor is not injective.

If ff is monic, then so are U→X→YU \to X \to Y and U′→X→YU^{\prime } \to X \to Y . Therefore they are their own images (2.2.8). The rest follows from the fact that subobjects of subobjects of YY can be naturally regarded as subobjects of YY (2.2.1). □

We have the following characterization of kernels using the image functor.

Proposition 2.3.5#

Let f:X→Yf : X \to Y be a map. Now the kernel of ff is the largest subobject KK of XX s.t. fK=0f K = 0.

Proof#

The kernel is a subobject of XX. If fK=0f K = 0, then K→X→Y=0K \to X \to Y = 0 by 2.2.15, and K→XK \to X factors trough the kernel, i.e., KK is contained in the kernel of ff. □
