Definition 9.69 · Thickening, square-zero extension#

Let 𝒞\mathcal{C} be a category and TT a class of maps in 𝒞.\mathcal{C}. A map f:Y→Xf:Y\rightarrow X in 𝒞\mathcal{C} is called a TT -epimorphism (resp. TT -monomorphism;T;T -isomorphism) if, for every commutative square

Remark 9.83#

Let TT be a class of maps in 𝒞.\mathcal{C}.

(i) Every monomorphism is a TT -monomorphism and every isomorphism is a TT -isomorphism.

(ii) A map is a TT -isomorphism if and only if it is both a TT -epimorphism and a TT -monomorphism.

(iii) Suppose that the diagonal Δf\Delta _{f} exists in 𝒞.\mathcal{C}. Then ff is a TT -monomorphism if and only if Δf\Delta _{f} is a TT -epimorphism.

Example 9.84 · Lifting properties in Set#

Let 𝒞\mathcal{C} be the category of sets.

(i) If T={∅→∗},T=\{\varnothing \rightarrow \ast \}, then a map is a TT -epimorphism (resp. TT -monomorphism; TT -isomorphism) if and only if it is surjective (resp. injective; bijective). The same holds whenever TT is a collection of injective maps containing at least one non-surjective map.

(ii) If T={∗⊔∗→∗},T=\{\ast \sqcup \ast \rightarrow \ast \}, then all maps are TT -monomorphisms, and a map is a TT -epimorphism if and only if it is injective. The same holds whenever TT is a collection of surjective maps containing at least one non-injective map.

Example 9.85 · Projective and injective modules#

Let RR be a ring. An RR-module MM is projective if and only if every surjective map has the right lifting property with respect to {0→M}.\{0\rightarrow M\}. Dually, MM is injective if and only if the map M→0M\rightarrow 0 has the right lifting property with respect to all injective maps.

Proposition 9.86#

Let 𝒞\mathcal{C} be a category and TT a class of maps in 𝒞.\mathcal{C}\textit{.}

(i) The classes of TT -epimorphisms, TT -monomorphisms, and TT -isomorphisms are closed under base change and composition.

(ii) The classes of TT -monomorphisms and TT -isomorphisms are closed under limits in Ar(𝒞).\mathcal{C})\textit{.}

(iii) If g∘fg\circ f is a TT -epimorphism and gg is a TT -monomorphism, then ff is a TT -epimorphism. If g∘fg\circ f is a TT -monomorphism, then ff is a TT -monomorphism. If g∘fg\circ f is a TT -isomorphism and gg is a TT -monomorphism, then ff is a TT -isomorphism.

(iv) Let T′T^{\prime} be the closure of TT under cobase change and composition. Then TT -epimorphisms and T′T^{\prime}-epimorphisms coincide, and the same holds for monomorphisms and isomorphisms.

(v) Let T′T^{\prime} be the closure of TT under colimits in Ar(𝒞).\mathcal{C})\textit{.} Then TT -monomorphisms and T′T^{\prime}-monomor-phisms coincide, and the same holds for isomorphisms.

Remark 9.98#

By Example 9.87(iv), smooth, unramified, and étale morphisms of schemes satisfy their respective lifting property with respect to arbitrary thickenings of rings, and the latter two even with respect to arbitrary thickenings of algebraic functors.

Remark 9.99#

The proof of the local nature of formal smoothness (Corollary 9.96) relies on the highly nontrivial fact that projectivity of modules is a Zariski-local property (Proposition 2.77(iv)). However, this fact is not used in Theorem 9.95.
