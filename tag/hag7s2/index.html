Separatedness

Section 7.2 · Schemes

Definition 7.25 · Locally separated, separated#

A morphism of algebraic functors f:Y→Xf:Y\rightarrow X is locally separated if its diagonal Δf:Y→Y×XY\Delta _{f}:Y\rightarrow Y\times _{X}Y is an immersion, and it is separated if Δf\Delta _{f} is a closed immersion. An algebraic functor XX is locally separated (resp. separated) if the unique map X→X\rightarrow Spec(ℤ)\mathbb{Z}) is, i.e., if the diagonal ΔX:X→X×X\Delta _{X}:X\rightarrow X\times X is an immersion (resp. a closed immersion).

For schemes, “locally separated” turns out to be vacuous, so this notion is rarely used:

Proposition 7.27 · Closure properties of separated morphisms#

(i) Consider a commutative triangle of algebraic functors

If ff and gg are separated, so is h.h\textit{.} If hh is separated, then so is g.g\textit{.} If hh is a closed immersion and ff is separated, then gg is a closed immersion. The same results hold with “locally separated” and “immersion”.

If ff is (locally) separated, so is f′.f^{\prime}\textit{.} The converse holds if XX and YY are Zariski sheaves and gg is a Zariski-local epimorphism.

Example 7.29#

(i) Any monomorphism is separated, since its diagonal is an isomorphism.

(ii) Any affine scheme is separated: the diagonal of Spec(R)R) can be identified with Spec of the multiplication map R⊗R→RR\otimes R\rightarrow R (which is the diagonal of RR in CAlg which is surjective. More generally, any affine morphism and hence by (i) any quasi-affine morphism is separated.

(iii) If AA is an ℕ\mathbb{N}-graded ring, then Proj(A)A) is separated: using the standard affine open covering of Proj(A)A) and Proposition 7.27(ii), this follows from the observation that the multiplication maps A(f)⊗A(g)→A(fg)A_{(f)}\otimes A_{(g)}\rightarrow A_{(fg)} are surjective. More generally, if AA is a quasi-coherent ℕ\mathbb{N}-graded algebra over X,X, then Proj(A)→XA)\rightarrow X is separated. In particular, any projective morphism and hence by (i) any quasi-projective morphism is separated.

(iv) The affine line with doubled origin (Example 4.48) is not separated.
