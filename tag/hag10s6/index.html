Example 10.92#

If RR is an integral domain, Proposition 10.91 identifies Pic(R)R) with the quotient of the group of invertible fractional ideals (i.e., sublines of Frac(R))R)) by the subgroup of principal fractional ideals. For example, if RR is a Dedekind domain, then Pic(R)=0R)=0 if and only if RR is a principal ideal domain (or equivalently a unique factorization domain).
