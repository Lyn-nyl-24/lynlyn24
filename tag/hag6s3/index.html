Remark 6.40#

The assumption that 𝒞\mathcal{C} is small can be replaced with the following weaker assumption: for every X∈𝒞,X\in \mathcal{C}, there exists a small collection JJ of τ\tau-covering sieves on XX such that every τ\tau-covering sieve on XX contains a sieve in J.J. This assumption holds for example for the Zariski and fppf topologies on CAlg so that Zariski sheafification and fppf sheafification of algebraic functors make sense. However, it does not hold for the fpqc topology on CAlg and indeed fpqc sheafification does not exist.

Definition 6.43 · Local epimorphism, monomorphism, isomorphism#

Let (𝒞,τ)(\mathcal{C},\tau ) be a site, let f:F→Gf:F\rightarrow G be a map in P(𝒞),\mathcal{C}), and let Δf:F→F×GF\Delta _{f}:F\rightarrow F\times _{G}F be its diagonal.

(ii) ff is a τ\tau-local monomorphism if its diagonal Δf\Delta _{f} is a τ\tau-local epimorphism.

(iii) ff is a τ\tau-local isomorphism if it is both a τ\tau-local epimorphism and a τ\tau-local monomorphism.

Proposition 6.44#

Let (𝒞,τ)(\mathcal{C},\tau ) be a small site and let ff be a morphism in P(𝒞).\mathcal{C})\textit{.} Then a is an epimor-phism in Sh if and only if ff is a τ\tau-local epimorphism. The same statement holds for monomorphisms and for isomorphisms.

Warning 6.46#

A map in Sh is a monomorphism in Sh if and only if it is a monomorphism in P(𝒞)\mathcal{C}) (since the inclusion Sh P(𝒞)\mathcal{C}) preserves limits and hence monomorphisms). However, the corresponding statement for epimorphisms does not hold: epimorphisms in Sh are usually not epimorphisms in P(𝒞),\mathcal{C}), i.e., they are not objectwise surjective. For example, if RR is a ring and (f,g)=(f,g)= R,R, then Spec(Rf×Rg)→R_{f}\times R_{g})\rightarrow Spec(R)R) is an epimorphism in Sh(CAlg since it is a Zariski-local epimorphism, but it is not objectwise surjective (unless ff or gg is a unit).
