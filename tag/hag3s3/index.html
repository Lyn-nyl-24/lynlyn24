Remark 3.26#

(ii) A technical difference between affine and projective spaces is that 𝔸I\mathbb{A}^{I} is quasi-compact for all II (this property will be defined in §7.3), whereas ℙI\mathbb{P}^{I} and 𝔸I−0\mathbb{A}^{I}-0 are quasi-compact if and only if II is finite.
