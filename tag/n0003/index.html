Tag 0002

Relative URLs for static sites

Resolve internal links and assets beneath a project site's path.

  • The project path
  • Build-time resolution
  • References

The project path

Suppose the home page is https://example.invalid/notebook/. A URL beginning with /assets/ resolves from the host root. A relative URL such as assets/site.css resolves from the current document's directory.

Build-time resolution

From a page under tag/n0001/, the relative path to the stylesheet is ../../assets/site.css. Ordinary links work at either the host root or a project subpath because the relative positions of pages stay fixed.

A custom 404 page can be served at arbitrary depths. Its links use the basePath declared in site.json, which must match the deployed project path.
