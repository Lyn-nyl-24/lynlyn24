정적 사이트의 상대 URL

프로젝트 사이트 경로 아래에서 자산과 내부 링크를 해석하는 방법을 정리합니다.

  • 사이트의 경로
  • 생성 시 경로 계산
  • 참고

사이트의 경로

프로젝트 사이트의 첫 페이지가 https://example.invalid/notebook/이라면, 문서에 적힌 /assets/site.css는 사이트의 경로 접두사를 건너뛰고 호스트 루트의 자산을 가리킵니다. 반면 assets/site.css는 현재 문서의 디렉터리를 기준으로 해석됩니다.

생성 시 경로 계산

이 블로그는 일반 문서에서 상대 링크를 생성합니다. 예를 들어 tag/n0001/에서 자산을 가리킬 때는 ../../assets/site.css를 사용합니다. 같은 산출물을 호스트 루트나 저장소 하위 경로에 두어도 일반 문서 사이의 상대 위치는 같습니다.

404 페이지는 요청 URL의 깊이를 미리 알 수 없어 site.json의 basePath를 사용합니다. 프로젝트 이름이나 도메인 구성이 달라지면 이 값을 바꾼 뒤 다시 빌드합니다.
