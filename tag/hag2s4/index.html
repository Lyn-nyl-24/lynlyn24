Section 2.4 · Affine geometry

Example 2.29 · The final scheme#

The constant functor CAlg →\rightarrow Set sending every ring to a one-point set is isomorphic to Spec(ℤ)\mathbb{Z}) and hence is an affine scheme. This is the final object of Fun(CAlg Set).
