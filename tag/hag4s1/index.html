Example 4.5 · Subcategories of modules#

Any property of modules that is preserved by extension of scalars defines a subfunctor of Mod CAlg →\rightarrow Cat. This holds for the following properties, and any combination thereof: finitely generated, finitely presented, flat, projective, free, vector space, line, etc.

Remark 4.9 · Colimits of categories#

Once limits have been defined, we can also define colimits: given F:ℐ→F:\mathcal{I}\rightarrow Cat, an extension Cat is called a colimit diagram if, for every category ℰ,\mathcal{E}, the functor

is a limit diagram. One can show that colimits of categories always exist, although they are difficult to describe explicitly in general.
