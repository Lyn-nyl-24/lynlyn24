Base change

Section 2.5 · Affine geometry

Given a ring map φ:k→k′,\varphi :k\rightarrow k^{\prime}, we can transform any system of polynomial equations Σ over kk into a system φ∗(Σ)\varphi ^{\ast}(\Sigma ) over k′k^{\prime} by applying φ\varphi to all the coefficients. More generally, many types of data over kk can be transformed into data over k′k^{\prime} using φ,\varphi , a process known as base change, change of coefficients, or extension of scalars. Other examples are the functor φ∗:\varphi ^{\ast}: Mod Mod sending a kk-module MM to the k′k^{\prime}-module M⊗kk′,M\otimes _{k}k^{\prime}, and the functor φ∗:\varphi ^{\ast}: CAlg CAlg sending a kk-algebra AA to the k′k^{\prime}-algebra A⊗kk′.A\otimes _{k}k^{\prime}. Unraveling these constructions, we see that there is a canonical isomorphism of k′k^{\prime}-algebras

In this section, we investigate the related process of transforming an algebraic kk-functor into an algebraic k′k^{\prime}-functor.
