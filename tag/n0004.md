## Titles and references

Titles and topics can change as a collection grows. Assign a stable tag on first publication so that older references continue to resolve to the same note.

## Linking to a result

The Markdown link `[Equivalence relations](tag:n0001)` points to [the note on equivalence relations](tag:n0001). The link `[Partition proposition](ref:prop:partition)` points to [the specific proposition](ref:prop:partition). The permanent reference page for a label survives moving the result to another note. Retired tags and labels should never be reassigned.
